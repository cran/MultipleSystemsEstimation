Reproducing the 2024 BIC bootstrap investigations

Introduction

This vignette is a computational appendix to Silverman, Chan and Vincent (2024), Bootstrapping multiple systems estimates to account for model selection. It provides R code for selected investigations underlying the tables and figures in that paper using the installed version of MultipleSystemsEstimation. Readers should consult the paper for the results themselves: the published tables and figures are not duplicated here.

The purpose is to reproduce the analyses, not to preserve the precise R code used in 2024. Where appropriate, the calculations use current package functions. This is not a tutorial; see BIC model selection and bootstrap inference for guidance on the methodology and its routine use.

The paper’s Table 1, on existence of the extended maximum likelihood estimate, is not reproduced here; the package provides check_extended_MLE() for investigating this question. Tables 2–5 and Figures 3–4 are covered by the calculations below. The blocks for Figures 1–2 cover finite values of ntop only, and Table 6 is illustrated by the Korea calculation rather than reproduced in full. No plotting code is supplied.

The estimates and confidence limits returned by the internal routines below refer to total population, including the observed cases. The public interface separately reports total population and the dark figure.

The New Orleans calculations in Silverman, Chan and Vincent (2024) used a 186-case version obtained from Table 1 of Bales, Murphy and Silverman (2020), which contained a small error. The package data have since been corrected to the 185-case version used in the original New Orleans analysis. The calculations in this vignette use those corrected data. Consequently, the New Orleans confidence limits, model rankings and population estimates may differ from the published results, even when the same computational settings are used. This qualification applies to all New Orleans calculations below.

Running the reproduction code

By default, the reproduction code is displayed but not evaluated when the vignette is built. Set run_examples <- TRUE in the initial setup chunk to execute it. The calculations underlying the figures store their numerical results in R objects without printing them. Readers can run the code in R and examine those objects as required.

For a shorter trial run, leave quick_check <- TRUE. This uses 10 bootstrap replications and limits the confidence-limit calculations to ntop = 2. For Table 4 and Figure 4 it uses the small Korea dataset in place of each requested dataset, so repeated results in those sections are intentional.

Quick mode checks that the code runs; it does not reproduce the paper’s results or give reliable confidence limits. It still searches the original data for candidate models, so five-list calculations can take some time. The Korea substitutions do not test the larger datasets.

To run the full calculations, set run_examples <- TRUE and quick_check <- FALSE. This uses 1000 bootstrap replications, finite searches up to ntop = 60, and unrestricted searches where specified. Some calculations involve extensive model searches or neighbourhood orderings and can be time-consuming. Numerical results may differ from those in the paper because of data corrections or changes in implementation.

Run the following setup before the calculations below. It loads the data and the specialist internal functions used for these investigations. For routine analysis, use the public functions described in the methodology vignette linked above.

# This check applies to the complete candidate space, before any ntop restriction.
checked_assemble <- function(zdat, maxorder, expected_models = NULL) {
  z <- assemble_bic(zdat, maxorder = maxorder)
  if (!isTRUE(z$enumeration_maxorder == z$requested_maxorder)) {
    stop("Enumeration order was reduced: requested ", z$requested_maxorder,
         "; actual ", z$enumeration_maxorder,
         ". Increase maxmodel before treating this search as exhaustive.")
  }
  if (!nrow(z$res)) stop("No candidate model has a valid original-data fit.")
  if (!is.null(expected_models) && nrow(z$res) != expected_models) {
    stop("Expected ", expected_models, " valid models, but found ", nrow(z$res),
         ". Check the package version and data before comparing with the paper.")
  }
  z
}

Results may differ between package versions. The setup checks the data, model counts and requested searches, and only reports a problem if a check fails. These checks repeat the original-data fits, but do not run bootstraps.

A missing confidence limit (NA) means that a required fit or the BCa acceleration could not be obtained. The confidence-limit routine omits unsuccessful bootstrap estimates; missing limits should be investigated before using the results. Limits based on ten replications are only a check that the code runs, not a basis for inference.

Further investigations from the 2024 paper

Table 4: Location of the bootstrap BIC minimum

For each bootstrap sample, an exhaustive search finds the BIC-minimising model. Its position in the original-data BIC ordering is then recorded. Cumulative counts at selected ranks correspond to Table 4. Replications with no finite BIC are reported separately rather than silently discarded. The code is potentially expensive, particularly for five-list data.

bootstrap_optimal_ranks <- function(zdat, maxorder, nboot = 1000, iseed = 1234) {
  # Exercise the exhaustive-search code on a small dataset in quick mode.
  if (quick_check) {
    zdat <- Korea
    maxorder <- 2
  }
  z <- checked_assemble(
    zdat, maxorder = maxorder
  )

  z <- bootstrapcal(
    z, nboot = nboot, iseed = iseed
  )

  original_order <- order(z$res[, "BIC"])

  vapply(seq_len(nboot), function(b) {
    v <- z$bootbic[, b]
    ok <- which(is.finite(v))
    if (!length(ok)) return(NA_integer_)

    best <- ok[which.min(v[ok])]
    match(best, original_order)
  }, integer(1))
}

rank_counts <- function(r, ntop = c(1, 5, 10, 50, 100)) {
  vapply(
    ntop,
    function(k) sum(r <= k, na.rm = TRUE),
    integer(1)
  )
}

ranks4 <- list(
  Kosovo = bootstrap_optimal_ranks(
    Kosovo, maxorder = ncol(Kosovo) - 2, nboot = nboot
  ),
  UK2 = bootstrap_optimal_ranks(UKdat_5, maxorder = 2, nboot = nboot),
  UK4 = bootstrap_optimal_ranks(UKdat_5, maxorder = 4, nboot = nboot),
  NewOrleans2 = bootstrap_optimal_ranks(NewOrl_5, maxorder = 2, nboot = nboot),
  NewOrleans4 = bootstrap_optimal_ranks(NewOrl_5, maxorder = 4, nboot = nboot)
)

sapply(ranks4, rank_counts)

# Counts above exclude failed replications; disclose their denominator.
rank_diagnostics4 <- t(vapply(ranks4, function(r) {
  c(attempted = length(r), usable = sum(is.finite(r)),
    failed = sum(!is.finite(r)))
}, numeric(3)))

Figure 4: Rank of the bootstrap-optimal model

For each bootstrap replication, the globally optimal model is located and its ranks under the ordinary BIC and degree-2 orderings are recorded. The pairs of ranks underlying Figure 4 are returned as data frames. As in the paper, replications whose ordinary rank is one are omitted from these pairs. Counts of usable, failed and rank-one replications are reported separately. The computation requires exhaustive model searches and is therefore not evaluated by default.

bootstrap_rank_pair <- function(zdat, maxorder,
                                nboot = 1000, iseed = 1234) {
  # Exercise the exhaustive-search code on a small dataset in quick mode.
  if (quick_check) {
    zdat <- Korea
    maxorder <- 2
  }
  z <- checked_assemble(
    zdat, maxorder = maxorder
  )

  z <- bootstrapcal(
    z, nboot = nboot, iseed = iseed
  )

  r1_order <- order(z$res[, "BIC"])

  r2_order <- degree2_order(
    rownames(z$res),
    nlists = ncol(z$xdata) - 1,
    maxorder = z$maxorder
  )

  r1 <- rep(NA_integer_, nboot)
  r2 <- rep(NA_integer_, nboot)

  for (b in seq_len(nboot)) {
    v <- z$bootbic[, b]
    ok <- which(is.finite(v))
    if (!length(ok)) next

    best <- ok[which.min(v[ok])]
    r1[b] <- match(best, r1_order)
    r2[b] <- match(best, r2_order)
  }

  usable <- is.finite(r1) & is.finite(r2)
  keep <- usable & r1 > 1

  pairs <- data.frame(
    ordinary = r1[keep],
    degree2 = r2[keep]
  )
  attr(pairs, "replication_counts") <- c(
    attempted = nboot, usable = sum(usable), failed = sum(!usable),
    rank_one_omitted = sum(usable & r1 == 1), retained_pairs = sum(keep)
  )
  pairs
}

kos_rank <- bootstrap_rank_pair(
  Kosovo,
  maxorder = ncol(Kosovo) - 2, nboot = nboot
)

no2_rank <- bootstrap_rank_pair(NewOrl_5, maxorder = 2, nboot = nboot)
no4_rank <- bootstrap_rank_pair(NewOrl_5, maxorder = 4, nboot = nboot)
uk2_rank <- bootstrap_rank_pair(UKdat_5, maxorder = 2, nboot = nboot)
uk4_rank <- bootstrap_rank_pair(UKdat_5, maxorder = 4, nboot = nboot)

  UK2 = uk2_rank,
  UK4 = uk4_rank
)

Table 6: Downhill model search

Section 5.2 compares downhill search with exhaustive model enumeration. The current package contains separate internal routines for fitting, bootstrap replication and jackknife acceleration. For example, the Korea calculation can be carried out as follows:

downhill_korea <- list(
  estimate = downhill_fit(
    counts = Korea[, ncol(Korea)],
    desmat = Korea[, -ncol(Korea), drop = FALSE],
    maxorder = 2
  ),
  bootreps = downhill_bootstrapcal(
    Korea,
    nboot = nboot,
    iseed = 1234,
    maxorder = 2
  ),
  ahat = downhill_jackknifecal(
    Korea,
    maxorder = 2
  )
)

c(
  estimate = downhill_korea$estimate,
  acceleration = downhill_korea$ahat
)

usable <- is.finite(downhill_korea$bootreps)
downhill_korea$replication_counts <- c(
  attempted = length(usable), usable = sum(usable), failed = sum(!usable)
)
downhill_korea$replication_counts

downhill_korea$confidence_limits <- NULL
if (quick_check) {
  message("Korea BCa limits omitted: ten replications are insufficient for meaningful tail estimates.")
} else if (!all(usable) || !is.finite(downhill_korea$estimate) ||
           !is.finite(downhill_korea$ahat)) {
  warning("Korea BCa limits omitted: investigate failed fits or unavailable acceleration.")
} else {
  # Extreme bias correction can make BCa probabilities undefined.
  p_below <- mean(downhill_korea$bootreps < downhill_korea$estimate)
  if (p_below == 0 || p_below == 1) {
    warning("Korea BCa limits omitted: all bootstrap estimates lie on one side of the point estimate.")
  } else {
    downhill_korea$confidence_limits <- bcaconfvalues(
      bootreps = downhill_korea$bootreps,
      popest = downhill_korea$estimate,
      ahat = downhill_korea$ahat,
      alpha = c(0.025, 0.975)
    )
    downhill_korea$confidence_limits
  }
}

In full mode this completes the Korea illustration with 95% BCa limits for total population. Quick mode omits those limits: ten bootstrap replications are insufficient for meaningful tail estimates. Full-mode limits are also withheld if any bootstrap estimate, the original estimate or acceleration is unavailable; failed replications are not silently removed.

The other rows of Table 6 involve additional datasets and search settings. In particular, the five-list UK downhill result used several additional order-2 starting models, because the main-effects starting model can converge to a secondary local minimum. The Korea code above is therefore an illustration of the present computational interface, not a complete reproduction of every row in Table 6. Completing that reproduction requires specifying and documenting those additional starting-model calculations. The present downhill_fit() interface always starts from the main-effects model and has no argument for alternative starting models; those calculations are outside the scope of this vignette. The corrected New Orleans data also affect comparisons with the published rows.

Summary

The displayed code covers selected computational investigations from the 2024 paper using the installed package. Table 1 is omitted; Figures 1–2 are covered for finite ntop only; and Table 6 is illustrated by Korea, with its interval calculated only in full mode. Tables 2–5 and Figures 3–4 are covered by numerical calculations, without plotting code. By default, computational chunks are displayed but not evaluated. Set run_examples <- TRUE to run them, using quick_check <- TRUE for reduced computational checks or quick_check <- FALSE for the full settings described above. Differences may arise from corrections to the New Orleans data or later developments in the implementation.
